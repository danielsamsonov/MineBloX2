# MineBloX 0.2 — Games + Studio

MineBloX — серверная система в стиле Roblox для Minecraft. Клиентские моды НЕ обязательны.

## Новое

### 🎮 Меню выбора игр
`/mineblox` открывает главное меню, а кнопка «ИГРАТЬ» открывает каталог игр.
Также есть `/places`.

Нажатие на игру переносит игрока в мир этого плейса.

### 🧱 MineBloX Studio
Для OP доступна кнопка «СТУДИЯ» или команда:

`/studio`

Затем выбери плейс. Игрок переводится в Creative + Flight и может моделировать сцену обычными инструментами Minecraft: блоки, здания, декорации и механизмы.

Можно также открыть редактор напрямую:

`/studio <place-id>`

Выйти:

`/studio exit`

## Создание игры

1. Создай/импортируй Minecraft world на хостинге.
2. Выполни:

`/place create mygame myworld My First Game`

3. Выполни:

`/studio mygame`

4. Построй игру в Creative.
5. Настрой спавн:

`/place setspawn mygame`

6. Игроки увидят её в меню «ИГРАТЬ».

## Что означает «редактор» в этой версии

Это первая версия Studio: она использует встроенные инструменты Minecraft Creative. Это надёжнее и не требует модов. В следующей версии можно добавить настоящий GUI-редактор: выбор блоков, кисти, копирование/вставка областей, удаление объектов, шаблоны, сохранение и публикацию плейса.

## Сборка

Нужны JDK 21 и Maven:

`mvn package`

Результат:

`target/MineBloX-0.2.0.jar`

Загрузить `.jar` в папку `plugins` Paper-сервера.
